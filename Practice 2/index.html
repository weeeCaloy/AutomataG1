Automata Theory Behind the Scenes

Deterministic Finite Automaton

Stage 1 — Lexical Analysis

A DFA is the simplest automaton model with a finite set of states and deterministic transitions. It has no memory beyond its current state.

In our system, the DFA scans the input string character by character, recognizing patterns like numbers, operators, and parentheses — producing a stream of categorized tokens.

Formal Definition M = (Q, Σ, δ, q₀, F)
  • Q = {START, INTEGER, DECIMAL, OPERATOR, LPAREN, RPAREN}
  • Σ = {0-9, ., +, −, *, /, (, ), space}
  • δ = Transition function (character-class based)
  • q₀ = START
  • F = {INTEGER, DECIMAL, OPERATOR, LPAREN, RPAREN}

Pushdown Automaton

Stage 2 — Syntax Analysis

A PDA extends the DFA with a stack memory, enabling it to handle context-free grammars — like nested parentheses and operator precedence.

Our PDA implements the Shunting-Yard algorithm, converting infix expressions to postfix (Reverse Polish Notation) using stack-based operator management.

Formal Definition M = (Q, Σ, Γ, δ, q₀, Z₀, F)
  • Γ = Stack alphabet {+, −, *, /, (, ⊥}
  • Z₀ = ⊥ (bottom-of-stack marker)
  • Handles operator precedence and associativity
  • Validates balanced parentheses

Turing Machine

Stage 3 — Evaluation

The Turing Machine is the most powerful model of computation with an infinite tape and a read/write head. It can compute anything that is computable.

Our TM reads the postfix expression from its tape, using a value stack to evaluate operations step-by-step, writing the final result back to the tape.

Formal Definition M = (Q, Σ, Γ, δ, q₀, q_accept, q_reject)
  • Reads postfix tokens from tape cells
  • Uses an evaluation stack for operands
  • Moves head right after each read
  • Writes result when tape is exhausted
